# Умный дневник

## 1. Идея продукта

Умный дневник — это Telegram-бот для управления личными делами. Бот позволяет пользователю создавать напоминания, устанавливать будильники, хранить заметки и получать уведомления в нужное время.

## 2. Цель продукта

Помочь пользователю организовать своё время, не забывать важные задачи и быстро сохранять важную информацию через Telegram.

## 3. Пользователи

- Студенты
- Работающие люди
- Предприниматели
- Пользователи, которым нужен простой личный помощник в Telegram
